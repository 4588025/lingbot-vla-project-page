让慢速 π₀ 提供长期规划，让快速策略完成即时纠正。

后续改进同时从数据与控制两侧推进：通过多场景采集和高质量示范提升策略泛化，再借鉴 Real-Time EXPO-FT，在动作下发前利用最新观测修正候选 chunk。

DATA IMPROVEMENT

扩展场景覆盖，提高示范质量。

数据侧优先解决训练分布单一和示范噪声问题，使策略在物体位置、光照、背景和相机视角变化时仍能稳定完成顺序抓取与堆叠。

DATA · COVERAGE

多场景采集

在保持任务语义一致的前提下，系统改变红蓝物块初始位置、指定平台位置、桌面背景、光照强度与方向，并加入小范围相机视角扰动。通过覆盖更多真实部署条件，降低策略对单一场景布局的依赖。

DATA · QUALITY

高质量示范

建立统一成功标准，优先保留抓取稳定、路径清晰、放置准确且无多余停顿的示范；剔除夹取失败、碰撞、长时间静止和不可恢复轨迹，并对关键接触与堆叠阶段进行质量复核。

RL POST-TRAINING

三条可继续验证的 VLA 强化学习路线。

三种方法分别从紧凑表示、异构经验和示范质量切入，可结合真机数据规模、安全约束与训练成本分阶段验证。

ONLINE RL · COMPACT INTERFACE

RL Token

从预训练 VLA 暴露紧凑的 RL token，并在其上训练小型 actor–critic 头，以较低的更新成本细化动作，同时用 VLA 原始策略约束在线探索。适合先冻结 π₀ 主干，只训练轻量策略头。

RL Token paper
OFFLINE + ONLINE · CORRECTIONS

RECAP

通过 advantage-conditioned policy 统一利用专家示范、策略自主执行数据和人工接管纠偏。它与现有 DAgger 数据路径较匹配，可把成功示范、失败轨迹及接管片段共同用于离线预训练与真机专项优化。

RECAP paper
FILTER + AUGMENT + ONLINE RL

GR-RL

先使用任务进度价值过滤低质量示范，再进行形态对称增强，最后通过在线 RL 的潜空间噪声预测器修正部署行为。适合长时序、高精度任务，可与本项目的高质量示范筛选和数据增强路线结合。

GR-RL paper

REAL-TIME EXPO-FT

从“动作不断档”走向“执行前实时纠正”。

Receding Horizon 解决推理期间的停顿，但新 chunk 仍可能来自过期观测。轻量 Edit Policy 可在动作执行前读取最新状态、修正候选动作，再由 Q-function 选择价值更高的 chunk。
