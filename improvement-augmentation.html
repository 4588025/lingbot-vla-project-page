Future work / Data augmentation

Augment the whole trajectory,
not only the pixels.

The next data recipe should preserve physical consistency across vision, language, proprioception, actions, and the simulator.

Priority candidate

Bimanual morphological symmetry

For a genuinely symmetric dual-arm embodiment, one trajectory can produce a mirrored counterpart—but only when every modality is transformed together.

Beyond visual augmentation

Expand diversity at six levels.

The existing F1 recipe remains the visual baseline; these additions target state, action, semantics, physics, and closed-loop recovery.

Morphology

Left–right symmetry

Mirror coordinated dual-arm trajectories with robot-specific camera, state, action, and language transforms.

Simulation

Domain randomization

Regenerate trajectories with varied lighting, clutter, backgrounds, object poses, tabletop height, and camera calibration.

Proprioception

Calibration robustness

Add bounded encoder noise, zero-offset drift, latency, and observation dropout while retaining feasible robot states.

Action

Trajectory variants

Apply constrained timing changes, smooth perturbations, and alternate valid grasps only when labels remain executable.

Language

Instruction diversity

Use verified paraphrases, object aliases, spatial rewrites, and explicit left/right swaps tied to the transformed scene.

Closed loop

Recovery data

Collect policy rollouts, near-failures, retries, and corrective demonstrations instead of training only on clean success paths.

Adoption guardrails

Symmetry is powerful only when it is real.

Apply the transform per task and embodiment, not as an unconditional global switch.

Use when

The system is truly symmetric

Left and right arms share morphology and limits, cameras have calibrated mirror mappings, and the task remains valid after swapping spatial roles.

Reject when

Semantics or physics are asymmetric

Do not mirror handed tools, asymmetric joint limits, fixed one-sided fixtures, text that cannot be rewritten safely, or tasks whose success predicate changes under reflection.

Evidence: ByteDance Seed's GR-RL mirrors images, swaps wrist views, transforms proprioception/actions in world coordinates, and flips spatial language. Its reported gain motivates this candidate; it does not guarantee the same gain on RoboTwin or LingBot-VLA.
